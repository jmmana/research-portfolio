# Maintaining this portfolio

Keep this repository focused on research questions, concrete contributions and evidence. Update project cards when experiments or publication records change.

Before adding a result, include its dataset/split, metric, baseline, execution conditions and source artifact. Label work in progress and unexecuted experiments clearly.

Before adding a publication, verify title, authors, persistent identifier, version and publication status. Distinguish preprints from peer-reviewed articles.

Keep transcripts, private application drafts, recommendation records and funding correspondence in the separate private application repository. Add only information intentionally prepared for public academic review here.
